# Student Achievement & Portfolio Management System

A CBSE Class 12 Computer Science project for managing student profiles, academics, activities, achievements, volunteer work, goals, reports, leaderboards, and admin functions.

## Technologies Used

- Python 3
- Tkinter
- mysql.connector
- datetime

## Modules Included

- `main.py`: Main entry point for the application.
- `db.py`: Placeholder for database connection helpers.
- `login.py`: Placeholder for the login interface.
- `register.py`: Placeholder for the registration interface.
- `dashboard.py`: Placeholder for the student dashboard.
- `academics.py`: Placeholder for academic records.
- `activities.py`: Placeholder for activity records.
- `achievements.py`: Placeholder for achievement records.
- `volunteer.py`: Placeholder for volunteer records.
- `goals.py`: Placeholder for student goals.
- `reports.py`: Placeholder for report generation.
- `leaderboard.py`: Placeholder for leaderboard display.
- `admin.py`: Placeholder for admin tools.
- `validation.py`: Placeholder for validation helper functions.

## Instructions for Running the Project

1. Open the `StudentPortfolio` folder in Visual Studio Code.
2. Install the required package:

```bash
pip install -r requirements.txt
```

3. Run the project:

```bash
python main.py
```
